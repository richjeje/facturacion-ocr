Facturación OCR - Documentación mínima de migración y organización de archivos.

Este repositorio contiene una implementación de una solución de facturación OCR con módulos para ocr, procesamiento, generación de CFDI 4.0, y una API con servicios web (FastAPI) junto a una interfaz web (frontend).

Archivos esenciales ya organizados en:
- backend/       (lógica y API)
- frontend/      (UI, plantillas HTML, CSS, JS)
- docs/          (docs y notas de migración)
- QA/             (pruebas rápidas y scripts de QA)

Notas de organización: se han movido/elimando artefactos no esenciales para mantener el repositorio enfocado en el funcionamiento y pruebas.
